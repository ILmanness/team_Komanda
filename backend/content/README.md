# Редакционные материалы

`knowledge.json` получен из «Арена_переговоров_База_знаний (1).xlsx» (SHA-256 `f4861408bf0b03b9c476c0d3cbafb8ebca57b0cd65f9fcebfbca2e24093c6438`). Вторая присланная копия книги имеет тот же хеш.

`trainings.json` получен из «Арена_переговоров_техническая_таблица_тренировок_1.xlsx» (SHA-256 `3086610d1a83bf8cd1bc4dd4df2bef6863c4bc7f082fe74c46412dc8578b4bce`).

Все JSON-файлы входят в Docker-образ backend. При первом `docker compose up --build -d` сервис `content-import` публикует 4 темы, 29 материалов, 4 теста и 17 инструментов тренировки с 34 сценариями; после него `demo-seed` добавляет 2 сюжетных уровня. Повторный запуск не создаёт дубликатов.

`branching_trainings.json` версии 3.0 получен из `training_methods (2).xlsx` (SHA-256 `6a12eb9264a41145f4801cb55a7ed01b6fc530f1f83aa89ff73b69aca772bd8d`) и `training_principles (2).xlsx` (SHA-256 `0fa793e734aeb9246e11a47e91f64235bcf5a89b8e3800b581a6138c3421fcea`). В каталоге показываются методы (9) и принципы (8) в порядке строк исходных таблиц. У каждого инструмента два сценария; при новой попытке выбирается другой, если оба активны. Перед первым выбором доступна карточка инструмента. В режиме обучения разбор виден по ходу тренировки, в режиме практики — в конце. Подсказка запрашивается отдельно. Сохраняются выборы, исправления и накопленные последствия; итог формируется по фактически пройденному маршруту. Для обновления файла используйте `python tools/export_branching_trainings.py METHODS.xlsx PRINCIPLES.xlsx`, затем повторите импорт. Исходные XLSX нужны только для обновления контента, при установке проекта они не требуются.

Для обновления данных: `python tools/export_editorial_content.py KNOWLEDGE.xlsx TRAINING.xlsx`, затем `python -m app.admin.import_editorial --apply` внутри backend-контейнера. Импорт валидирует схему и маршруты, использует стабильные идентификаторы и сохраняет предыдущие игровые сессии.

Тесты базы знаний опубликованы для самостоятельной проверки; ответы открываются отдельно. В тренировках модель не вызывается. Результат определяется конечным узлом, а игроку показывается разбор выбранной траектории. Начатые сессии сохраняют снимок прежней версии сценария и могут быть завершены после импорта. Старые пошаговые тренировки сохраняют финальный свободный ответ для самопроверки. Повторный экспорт из XLSX заменяет соответствующий JSON-файл; сверяйте изменения перед импортом.
