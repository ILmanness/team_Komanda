# Контент и редактор администратора

Актуально на 29 сентября 2026 года. Редактор открыт по `/admin` после входа с ролью `admin`. API находится в `backend/app/admin/router.py`, формы — в `frontend/src/Admin.tsx`.

## Что создаёт администратор

1. **Сюжетную ветку**: название, адресное имя, описание и обложку.
2. **Сюжетную миссию**: ветку, порядок, персонажа, публичную ситуацию, задачу и первую реплику. Здесь игрок вводит текст; оценка и собеседник работают через AI.
3. **Персонажа**: имя, роль, видимое описание, поведение, PAEI-профиль, иллюстрацию и инструкцию для движка.
4. **Тему знаний**: материал, краткое описание и место в иерархии.
5. **Короткую тренировку**: одну ситуацию, ответы с последствиями, числовыми изменениями и подсказки.
6. **Пошаговую тренировку прежнего формата**: несколько последовательных ситуаций. На каждом шаге три варианта с разбором; неверный и частично верный ответ ведут к повтору с подсказкой. В финале игрок пишет ответ своими словами и сравнивает его с критериями и примером.
7. **Тренировку с развилками**: метод или принцип с порядком в каталоге, одним или несколькими сценариями, сценами, вариантами ответа, переходами и итогами. Варианты могут вести к новым решениям, последствиям или финалу. Для каждого ответа задаются реакция собеседника и разбор, который игрок увидит после завершения. AI в тренировках не вызывается.

## Порядок публикации

Новый материал создаётся как черновик. Сначала опубликуйте связанную сюжетную ветку или тему знаний, затем миссию или тренировку. Для публикации требуются персонаж и заполненная конфигурация. Старые сессии хранят снимок конфигурации и не меняются при редактировании миссии.

Пошаговые редакционные тренировки из `backend/content/trainings.json` импортируются автоматически. Они показываются в админке, но их содержание меняется через исходные редакционные данные и повторный импорт. Пошаговые тренировки, созданные в админке, можно редактировать там же. Их граф собирается и проверяется backend в `backend/app/admin/guided_authoring.py`.

Каталог игрока разделён на **Методы** (9 инструментов) и **Принципы** (8 инструментов) в порядке редакционных таблиц. Для каждого инструмента из `backend/content/branching_trainings.json` загружены два сценария. При запуске выбирается один активный сценарий, а следующая попытка предлагает другой, если оба доступны. Игрок видит только варианты, последствия и разбор своего пути; AI в этом режиме не вызывается. В админке можно создавать новые инструменты и редактировать импортированные: менять порядок, активность и вес сценариев, сцены, переходы, последствия и итоги. Сохранённые администратором изменения помечаются как `source=admin` и не перезаписываются при повторном импорте редакционного файла. Для возвращения к редакционной версии используйте новый импорт после удаления такой пометки из конфигурации в базе данных.

## Импорт исходных материалов

Источник базы знаний, восьми прежних пошаговых тренировок и 34 новых сценариев — JSON-файлы в `backend/content`. После изменения этих файлов выполните:

```sh
docker compose exec backend python -m app.admin.import_editorial --apply
```

Импорт проверяет переходы и достижимость финала; существующие игровые сессии продолжают использовать сохранённый снимок. Подробности происхождения файлов — в [README контента](../backend/content/README.md).

## Границы данных

Игроку передаются публичный контекст и варианты ответа. Оценки вариантов, скрытые правила, промпты и ключ провайдера остаются на backend. `GET /api/v1/missions/{id}/briefing` предназначен для подготовки игрока; административные методы требуют JWT администратора.
