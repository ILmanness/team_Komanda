# Фразы из исходных материалов для MVP-05

Собрано 681 уникальных текстов и 807 употреблений с указанием источника.

## Как читать набор

Текст фраз сохранён. Одинаковые фразы объединены, но каждое употребление сохраняет свой контекст и исходную оценку. Полные контексты и адреса находятся в разделе `source_catalog` файла `content/evaluator_reference_cases.json`.

В тренировках сохранены `correct`, `partial`, `incorrect`, этап попытки и фидбэк. Это оценки выбора в конкретном учебном узле. Они не превращены в `action_type`, PAEI fit или изменение игрового состояния.

Примеры для отдельных критериев отмечены `met` или `not_met` только для указанного критерия. Свободные ответы — возможные примеры; их соответствие всем критериям ещё нужно проверить. Реплики NPC и короткие фрагменты выделены по роли. В тестах базы знаний правильная буква относится только к заданному вопросу.

Документ PAEI содержит примеры, качественные оценки и вклад отдельных правил. Это не полный числовой эталон оценки хода. Новые итоговые оценки не назначались. Набор ожидает проверки Полины.

## Что проверить перед использованием как эталона

- Уточнить роли фраз из базы знаний, где автор реплики не указан.
- Для свободных ответов проверить каждый критерий и достаточные цитаты.
- Для PAEI-примеров подтвердить оценки в конкретном сценарии и профиле.
- При расширении набора оставить исходные учебные оценки отдельно от оценок игрового хода.
